## Addendum — 2026-06-20 psalms content ship

### What shipped

Three new Verses content games, plus a version bump across all three
Verses platforms (per user direction — see "Versioning decision" below):

| Psalm | Label | Levels | Chunks / Moves |
|---|---|---|---|
| 46 | WEB (updated) | 1 (whole) | 24 / 23 |
| 97 | NKJV | 2 (1–6 / 7–12) | 28 / 26 |
| 139 | WEB (updated) | 4 (1–6 / 7–12 / 13–18 / 19–24) | 55 / 51 |

Files: `content/verses/psalm-{46,97,139}/game.js`. Auto-discovered via
`import.meta.glob`; no engine/gameplay/scoring code edits. Platform
versions: tablet-verses v1.13 → v1.14, phone-verses v1.8 → v1.9,
phone-verses-sandbox v1.7 → v1.8.

### Scoping decisions (per psalm)

- **Psalm 139 (the original ask).** Whole psalm incl. imprecatory
  vv. 19–22 (user chose "whole psalm" over skip-19–22 or stop-at-18).
  4-level even thematic split. Line-based chunking, short fragments
  ("It's lofty.") kept as own chunks. The source file renders the
  divine name "LORD" rather than the standard WEB "Yahweh" — user
  chose to keep it as supplied and label it "WEB (updated)".
- **Psalm 97 (added in-session).** NKJV, 12 verses → 2 balanced levels
  (theophany 1–6 / response 7–12). NKJV "LORD" / "Lord" distinction
  preserved in v. 5.
- **Psalm 46 (added in-session).** WEB, 11 verses. User chose
  single-level (over the natural Selah 3-stanza split). "Selah" kept
  inline. "Yahweh" → "the LORD" in vv. 7, 8, 11 per user direction;
  labeled "WEB (updated)".

### Versioning decision (notable)

CLAUDE.md treats content as auto-discovered, so content-only adds
normally touch no platform file and skip version bumps. The user
overrode this for this ship: adding psalms *is* an updated version of
the game, so the version label should say so. All three Verses
platforms bumped in lockstep (the content appears on all three).
Consider updating CLAUDE.md's content-vs-versioning guidance to reflect
this preference so future content adds don't re-litigate it — **offered
to the user, not yet done.**

### Pre-existing drift discovered

`index.html` desc labels were stale from the 2026-05-25 ships: tablet
showed v1.12 (actual v1.13), phone-verses v1.6 (actual v1.8), sandbox
v1.4 (actual v1.7). Prepended the new version to each; did **not**
backfill the intermediate gaps (out of scope — that's the documented
"in-game version-label drift" cleanup backlog). Flagged to user.

### Build + verification

Ps. 23 → 46 → 91 → 97 → 139 → Matthew → Titus).
