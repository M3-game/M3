## Addendum — 2026-06-27 Session 2: tutorial component + panels 1–2 (tablet v11.19)

Second step of the tutorial plan (verses TODO #4). Built the portable
component and the first two shared panels on tablet arcade, with the look
iterated to the user's approval over the session.

### What shipped

- **New `core/Tutorial.jsx`** — the portable tutorial modal. **Option A
  architecture:** the component holds ALL panel definitions; each platform
  passes an ordered `sections` list (so arcade shows only the shared match
  panels) + a small `config` bundle (reserved for the verses/campaign panels
  and the real-scoring values). Paints the demo board with the real
  `drawTile`/`drawSpecialIcon` from `core/tileDrawing.js` → pixel-identical
  tiles. Self-contained canvas timeline engine (steps: pause/hand/drag/clear/
  form/gravity/rowclear) with a dragged-tile "carry" gesture, real popups, and
  a live score readout.
- **Two shared panels, 6×6:** (1) basic match — drag to make 3, they clear,
  tiles fall in; (2) line special — drag to make 4-in-a-row → a ⚡ line special
  forms (3 clear + 1 special) → then it's USED the real way: swapped INTO a
  match (a vertical 3) which consumes it and clears its whole row.
- **Tablet arcade v11.18 → v11.19:** opt-in "Tutorial" button (small pill,
  top-left of the header, mirrors the dark/light toggle; never auto-opens) +
  the modal (`sections={['basic-match','line-special']}`). No gameplay,
  scoring, or board-render change to the arcade itself.

### Key decisions made this session (look + correctness, from user review)

- **Button placement:** tablet arcade has no pre-game screen, so the button
  lives in the header (per the storyboard's trigger rule). Verses (later) puts
  it on the "Begin" passage screen instead.
- **Board sizing — REVISED from the storyboard's "one consistent board":**
  constant tile pixel size + the modal reserves the largest (8×8) footprint;
  smaller grids center inside it (modal never resizes). The grid GROWS in tiers
  as effects escalate: **6×6 basic/line → 7×7 bomb/cross → 8×8 novas/
  multipliers/fusion.** Comparison pairs share a size (bomb/cross both 7×7;
  super/hyper both 8×8) so the contrast is fair. Reason 6×6 is too small for
  the top tier: a 5×5 supernova / hypernova on a 36-tile board clears almost
  everything, so the two can't be told apart.
- **Animation:** slowed to **half speed** (`SPEED = 2`); the finger **drags
  the tile** from source to destination (carries it), modeling the real swap.
- **Hard-coded boards + match-free refill.** Each panel's full board is
  hand-authored so the ONLY available match is the intended one, at exactly the
  size being taught (no stray same-color tile turning a 3 into a 4). Refills
  are **deterministic** and pick only types that complete no run — and they
  only ever color BRAND-NEW falling tiles. **An existing tile never changes
  color** (an earlier "recolor a survivor" approach was rejected by the user as
  teaching the wrong thing; instead the boards are authored so survivors can't
  fall into a run — verified by simulation).
- **Illustrative scores (+60, +180)** sized to the 6×6 demo. Exact in-game
  numbers arrive with the real-scoring core extraction at panel 7.
