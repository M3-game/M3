## Addendum — 2026-04-25 Matt 5 v1.0 content shipped

First content-only session against the V-* engine. Three levels
covering Matthew 5:1–20, NKJV.

**Authoring workflow.** I drafted chunks per-section; user edited each
toward thematic-phrase chunks ("Blessed are X" entire phrase, etc.).
This produced longer chunks than Titus / Psalm 91 — long chunks
accepted to preserve phrasing intent. Pattern stabilized after
Beatitudes (level 1) and held through Salt and light + Fulfilling the
Law without re-decision.

**Wrapping decision.** Estimated ~22 of 50 chunks exceed ~40 chars
(the single-line limit at 20px Georgia bold in the 408px content
column) and will wrap to 2 lines when current. Considered:
- **Accept wrapping** (chosen). Lowest cost. Visual height-shift on
  long-chunk rows; board nudges down, returns when chunk advances.
- **Cap chunks at ~40 chars.** Would split "Blessed are X" pattern
  and other thematic phrases — rejected.
- **Per-chunk font override.** Engine change (~5 lines + data field).
  Parked in DEFERRED.md as a fallback if playtest reveals the
  height-shift is jarring.

Font-size reduction (20 → 19 → 18px) was estimated and rejected:
saves only ~1 wrap because most long chunks are 50–60 chars, well past
any of those thresholds. Visual hierarchy also floors at 18px (prior
chunks fixed at 15px — at 16px the size delta basically disappears).

**Translation note for upcoming content.** User flagged 2026-04-25:
**Isaiah 52:13–53:12 will be ESV**, not NKJV. James 1 stays NKJV.
First multi-translation game in the project — translation field on the
data file already supports it; just a content choice.

**Future Matt 5 levels are additive.** The wrapper engine reads
`levels[]` length without any "complete" gate, so the picker shows the
Matt 5 game as soon as the file exists. Adding 5:21+ in future
sessions just appends entries — no engine touches, no version bump on
the platform file.

**Bundle impact.** verses bundle 81.60 → 84.33 kB (+2.73 kB). Build
clean.
