## Addendum — 2026-04-28 N-1 verses content promotion shipped

First of two sessions enabling phone-418-verses (the other is N-2,
planned next). Pure refactor — game data moves out of a platform
directory to a neutral repo-root location, so the upcoming
phone-418-verses platform can import the same files without
either platform owning the others' content.

**Scoping pass (locked at session start, one-decision-per-message):**

Six decisions locked across the scoping discussion. All captured in
DEFERRED.md "Phone-418-verses (N-1, N-2)" entry. Summary:

1. **Content sharing.** Promote game files to neutral
   `content/verses/<slug>/game.js`. Single source of truth, both
   platforms import from there.
2. **Text-bar layout (form-factor) — for N-2.** Single-column stack;
   reference as a small italic label above each verse's first chunk;
   18px current / 14px prior chunks, Georgia.
3. **Board dimensions (form-factor) — for N-2.** 10×10 — matches
   tablet-verses (which dropped 12→10 ROWS in V-4) rather than
   diverging from arcade (10×12). **Target multiplier** locked at
   `moves × 250` for phone — divergence from tablet's `moves × 300`.
   Tablet's `× 250` parked option (per V-4 done entry) hasn't ramped;
   phone-418-verses adopting it from the start lets us A/B the two
   multipliers across form factors. Settled in build / playtest if
   `× 250` plays poorly.
4. **Bonus-moves carry handoff (form-factor) — for N-2.** Phone-scoped
   key `m3_arcade_carry_from_verses_phone418`. Tablet stays on its
   existing `m3_arcade_carry_from_verses` key. Matches 2026-03-23
   phone/tablet-distinct-runs principle.
5. **Session staging.** Two sessions (this N-1 + upcoming N-2).
6. **Index.html card + in-app picker layout — for N-2.** Separate
   per-platform card on index.html ("Phone Verses"). In-app picker
   uses compact cards (2-3 per row at 418px) — eventually adopted
   on tablet too as passage count grows.

**What shipped in N-1:**

- Created `content/verses/` at the repo root.
- Moved game folders out of `platforms/tablet-verses/games/`:
  `titus-2-11-13/`, `psalm-91/`, `matthew-5/`, `_template/`.
- Removed the now-empty `platforms/tablet-verses/games/` directory.
- Archived `platforms/tablet-verses/match3-v1.7-tablet-verses.jsx`
  to `platforms/tablet-verses/archive/`.
- Created `platforms/tablet-verses/match3-v1.8-tablet-verses.jsx` —

  - `import.meta.glob('./games/*/game.js', ...)` →
    `import.meta.glob('../../content/verses/*/game.js', ...)`
  - Slug-extraction regex updated for the new relative path
  - Doc-comment references updated (3 places in the version-history

  - In-app help text on the picker (when the games registry is empty)

## Addendum — 2026-04-28 N-2 phone-418-verses port shipped

Second of the two-session program scoped same morning. Phone-418 became
JSX in M-1 (2026-04-27), making this peer feasible. Forked from
tablet-verses v1.8 (the N-1 baseline); shares the
`content/verses/<slug>/game.js` directory N-1 established.

**What shipped:**

*New platform — `platforms/phone-418-verses/`:*
- `match3-v1.0-phone-418-verses.jsx` — fork of tablet-verses v1.8
  with form-factor adapts (full per-decision rationale in the file's
  v1.0 header comment block):
  - **Tile + board sizing:** `TILE_SIZE` 50→40, `TILE_GAP` 4→2 (board
    fits 418px width: 10 × 40 + 9 × 2 = 418px exactly). ROWS / COLS
    inherited from tablet-verses (10 × 10 already in V-4).
  - **Target multiplier:** `TARGET_PER_MOVE_DEFAULT` 300→250 — phone
    locks the lower multiplier from the start; tablet stays at 300.
    Real A/B across form factors in playtest.
  - **Text-bar render (rolling 3-chunk window):** two-column
    (110px / 1fr) → single-column stack. Reference rendered as
    13px italic label above each verse's first chunk. Current chunk
    18px / 600 (was 20px); prior chunks 14px (was 15px). Color
    inherits from row so reference dims/lights with current/prior
    state.
  - **Passage-modal + full-passage modal:** same single-column
    treatment, 16px chunks / 12px italic purple `#667eea` reference.
  - **Picker + level-select grids:** `minmax(220px, 1fr)` →
    `minmax(140px, 1fr)`, gap 16→12px, maxWidth 900→600px. Yields
    2 cards per row at 418px instead of 1.
  - **Storage (phone-scoped):**
    `VERSES_PROGRESS_KEY_PREFIX` `m3_verses_` → `m3_phone418_verses_`.
    New local `PHONE418_BANKED_MOVES_KEY = 'match3_phone418_bankedMoves'`
    constant replaces 5 active code references to the imported
    `BANKED_KEY` (the AdminPanel/STATS_KEY/defaultStats imports stay
    for arcade-fallback paths that VERSES_MODE never reaches at
    runtime — left inert per scope discipline).
  - **Carry handoff:** receipt key
    `m3_arcade_carry_from_verses_phone418` (was
    `m3_arcade_carry_from_verses`); navigation target `phone418.html`
    (was `tablet.html`).
