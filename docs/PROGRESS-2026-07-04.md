## Addendum — 2026-07-04 Session 4: tutorial port to tablet-verses (v2.0)

First of the tutorial ports. Wired the shared `core/Tutorial.jsx` modal into
tablet-verses and built the two verses-only panels that run after the 8 shared
match panels.

### Scope recovery note

The tablet-verses port had been scoped in a prior session but under-documented.
This session re-derived and locked the decisions with the user, then wrote them
into `docs/verses/tutorial-storyboard.md` ("Build plan — tablet-verses port")
before building, so the ports that follow don't re-litigate them. The five
locked decisions: Genesis 1:1 sample (baked once into `core/`), V1 built to
look like the real verses game, V2 plain-wording (no formula), the "Tutorial"
link on the passage-selection screen, and one major version bump.

### What shipped

- **`core/Tutorial.jsx` (edit-in-place):**
  - **V1 (`verse-reveal`)** — a real match board with the rolling text bar
    above it. Genesis 1:1 (from `content/verses/genesis-1-1-5/game.js`) is
    line-broken exactly as the game does: "In the beginning God" (pre-visible)
    → match reveals "created the heavens and the earth." → match reveals "The
    earth was without form, and void;". The reference shifts Gen. 1:1 → Gen. 1:2
    on the third line, mirroring the game. New engine bits: a `reveal` field on
    the clear step (fires the line the instant the match clears — no delay, per
    user direction) and the `VerseTextBar` renderer.
  - **V2 (`target-moves`)** — a static still (white background, no emojis)
    highlighting the Target Score + Moves Left, plus a replica of the
    Begin-screen "Play this level:" drill selector (1×–4×) to illustrate the
    multiple-play option. Wording stays conceptual (no exact formula).
- **Tablet-verses v1.17 → v2.0:** imports `Tutorial`, adds the opt-in
  "Tutorial" link at the top-left of the passage-selection screen (light pill on
  the purple background), and carries the 10-panel `sections` list. Major bump —
  the tutorial is a significant new screen landing whole. No verses
  gameplay/scoring/board change.

### Review refinements (this session)

- V1: switched from placeholder chunking to the real content-file line breaks
  (the "In the beginning God" break matters — theological point the user
  raised); made the reveal immediate (was a separate delayed step).
- V2: reworded the last sentence to the "for some passages…" phrasing; added
  the drill-selector replica; white background; dropped emojis.

### Verification

- `npm run build` clean after every change. V1's board is authored run-free at
  start; both scripted matches are isolated (match 1 clears cols 1–3, match 2
  uses cols 4–5 which gravity leaves untouched), so the reveal choreography is
  deterministic — same board every replay.

### Versioning note carried forward

Next tablet **arcade** change graduates to **v12.0** (not v11.27) to mark the
tutorial as a significant new screen — see the platform-status table.
