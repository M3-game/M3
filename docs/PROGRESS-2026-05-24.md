## Addendum — 2026-05-24 Isaiah 52:13–53:12 ESV verses content shipped

First non-NKJV game in the project. Five-level Servant Song authored
from a user-edited ESV draft that had been pending since 2026-04-26
(the Matt 5:31–48 half of that 2026-04-26 pair shipped 2026-05-04;
this is the second and final half).

**Scoping pass.** Five decisions worked through one at a time per
CLAUDE.md scoping discipline:

1. **Edited-draft handoff.** User confirmed an edited ESV draft was
   ready and shared it via a file in `~/Downloads/Isaiah 52.13-53`.
   Existing chunking was already done by the user via line breaks in
   the source doc; line-by-line read needed only minimal
   interpretation (strip indentation/trailing whitespace; move
   verse-number prefixes into `reference` field).
2. **Section count.** User initially said "4 sections" but corrected
   to "5 sections" on follow-up — the source doc has 5 blank-line-
   delimited stanzas of 3 verses each (the classical Servant Song
   stanza structure: 52:13–15 / 53:1–3 / 53:4–6 / 53:7–9 / 53:10–12).
   Five levels matches the source formatting directly.
3. **Slug.** User chose `isaiah-52-13-53` over Claude's proposed
   `isaiah-52-53` — explicitly signals the 52:13 start point while
   reading naturally (Isa. 53 has no v. 13, so no ambiguity in the
   "53" suffix). Pattern is a hybrid of Matt 5's chapter-only
   (`matthew-5`) and Titus's verse-range (`titus-2-11-13`) — fits
   the cross-chapter passage.
4. **Reference format.** `"Isa. 52:N"` / `"Isa. 53:N"` mirrors Matt
   5's `"Matt. 5:N"` and Psalm 91's `"Ps. 91:N"` abbreviation pattern
   to fit the 110px reference column on the in-game text bar. Eight
   characters before the verse number — well within the column.
5. **Title.** Top-level `title: "Isaiah 52:13–53:12"` (cross-chapter
   range), level titles per-stanza (`"Isaiah 52:13–15"`, `"Isaiah
   53:1–3"`, etc.). Matt 5 and Psalm 91 use chapter-only titles
   because they sit within one chapter; this passage crosses two
   chapters so the full range is needed for the picker card.

**Implementation.** New file
`content/verses/isaiah-52-13-53/game.js` with:
- `title: "Isaiah 52:13–53:12"`
- `translation: "ESV"` (first non-NKJV in the project)
- `levels[]` array with 5 entries, each containing 3 verses with
  per-verse `reference` + `chunks` arrays
- Per-level chunk counts: L1 13 / L2 13 / L3 12 / L4 14 / L5 19
- Per-level move counts: L1 12 / L2 12 / L3 11 / L4 13 / L5 18
- Total: 71 chunks / 66 moves across 5 levels

**Auto-discovery.** All three verses platforms (tablet-verses v1.12,
phone-verses v1.6, phone-verses-sandbox v1.4) load games via
`import.meta.glob('../../content/verses/*/game.js', { eager: true })`,
so the new directory + file is picked up at build time without any
platform-file edit. Verified across all three bundles.
