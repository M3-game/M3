## Items in this session

### Campaign file (v1.24 → v1.25)

1. **Transition pause 3s → 2s.** `TRANSITION_PAUSE_MS` constant for
   admin-tunable future.
2. **Bonus-moves cap at 99, warning at 90.** Existing moves retained when cap
   hit; only the ability to *earn more* is blocked. Header messaging:
   - `≥ 90 && < 99` — amber "Nearing cap — max 99."
   - `= 99` — red "Bonus-move cap reached — no additional moves can be earned."
   Silently drop earned moves past the cap (no "+1 bonus move" burst).
3. **"Are you sure?" confirm on in-header End-and-carry button** during active
   bonus-moves use, *when below target*. (Not fired from the bonus-moves
   prompt's End button — that's always a save.)
4. **Best campaign run** — new `CAMPAIGN_KEYS.bestRunScore`. Updated when L8
   is won. Displayed on:
   - **LevelSelect** — header subtitle "Best campaign run: N"
   - **CampaignComplete** — "🏆 New record!" badge if beaten, else "Best: N"
5. **Timed-mode grace window (1.5s)** after `timeLeft = 0` — during grace,
   `addTimeExtension` can fire and re-arm the timer. Uses a `graceActive`
   flag; main timer effect re-creates the interval if extension lands during
   grace.
6. **Export / import stats** in admin panel + **last-backed-up timestamp**.
   Manual safety net against iOS Safari ITP localStorage purge.
7. **Admin access from level-select screen** — long-press on "Campaign Mode"
   title (1.5s, mirroring score long-press), plus `?admin=1` URL param.
   Opens the existing admin panel.
8. **Stale header version label** (`v1.12` at [line 2090]) → `v1.25`.
