# Claude Code Quickstart (Cursor)

## 1. Open Cursor

Launch Cursor and open your project folder.

## 2. Install the Claude Code Extension

If you haven't already:

1. Open the Extensions panel — `Cmd+Shift+X`
2. Search for **Claude Code**
3. Click **Install**

## 3. Open Claude Code

Once installed, look for the Claude Code icon in the **Activity Bar** (left sidebar). Click it to open the Claude Code panel.

Alternatively:

- Open the Command Palette — `Cmd+Shift+P`
- Type **Claude Code** and select **Claude Code: Focus on Claude Code View**

## 4. Open Claude Code in a New Window

To give Claude Code its own dedicated window:

1. Open the Command Palette — `Cmd+Shift+P`
2. Type **new window** and select **Claude Code: Open in New Window**

This opens Claude Code in a separate Cursor window. You can move it to a second monitor or keep it alongside your main editor window.

## Tips

- You can also open Claude Code as a **full editor tab**: Command Palette → **Claude Code: Open in New Tab**
- Your preferred panel location is remembered between sessions
